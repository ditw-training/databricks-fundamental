English

Static edition for self-study. Open a workshop, solve each step on the page and run the code in your notebook. To check a step, load the checks once with %run ./_checks/<workshop> after the setup cells, then run check("<workshop>", "tNN") in a new cell.

  • Workshop I — Ingestion8 steps + 4 ⭐ optional · notebook WORKSHOP_ingestion
  • Workshop II — Delta Lake7 steps + 5 ⭐ optional · notebook WORKSHOP_delta
