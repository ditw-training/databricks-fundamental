UPDATE ... SET ... WHERE changes the columns of the rows that match the condition. SET can change several columns at once, separated by commas. Always add WHERE: without it every row in the table is updated. The old values stay readable with time travel until VACUUM removes the old files.

      Step 12 — RESTORE after an accidental delete

      OrderNot started

      DELETE FROM <table> without WHERE removes every row, but the old version is still in the history. RESTORE TABLE ... TO VERSION AS OF <n> rolls the table back to version n and records the restore as a new version. safe_version (from the ready cell) is the version before the accident. Time travel is not a backup: after VACUUM removes the old data files, those versions are gone. SQL equivalent of the key line: RESTORE TABLE lab_delta_cust_ws TO VERSION AS OF 12 (with your version number).
