W SQL to funkcje tabelaryczne i wyrażenia, które piszesz wewnątrz SELECT.

Przeciągnij każde pojęcie na jego opis albo wybierz je z listy obok opisu.

Pojęcia

  • read_files('/Volumes/<catalog>/default/datasets/customers/customers.csv', format => 'csv')
  • CASE WHEN year(registration_date) >= 2025 THEN 'New' ELSE 'Loyal' END
  • CAST(order_datetime AS TIMESTAMP)
  • try_cast(order_datetime AS TIMESTAMP)
  • _metadata.file_path
  • COUNT(*) AS order_count

Podpowiedzi dostępne: 3

  1. Podpowiedź 1

    Przeczytaj każde wyrażenie na głos: nazwy funkcji mówią, co robią (read_files, CAST, COUNT).

  2. Podpowiedź 2

    try_cast to wyrozumiały bliźniak CAST: ta sama konwersja, ale NULL zamiast błędu. _metadata to ukryta kolumna, która opisuje plik źródłowy.

  3. Rozwiązanie

    Pary: read_files(...) → czyta pliki jako tabelę; CAST(...) → zamienia albo zwraca błąd; try_cast(...) → zamienia albo zwraca NULL; CASE WHEN ... END → wartość według warunku; COUNT(*) AS order_count → liczy wiersze; _metadata.file_path → ścieżka pliku źródłowego.

Dzięki prefiksowi F wbudowane funkcje Pythona, takie jak sum() czy max(), nadal działają. Dopasuj każde wyrażenie PySpark do kodu SQL, który robi to samo.

Pojęcia

  • F.col("city")
  • F.year(F.col("registration_date"))

Podpowiedzi dostępne: 3

    Czytaj kod PySpark jak SQL: nazwa funkcji zwykle się nie zmienia (year → year, count → COUNT).

  2. Podpowiedź 2

  3. Rozwiązanie

    Pary: F.col("city") → city; F.year(...) → year(registration_date); F.count("*").alias(...) → COUNT(*) AS order_count; F.when(...).otherwise(...) → CASE WHEN ... END; .cast("timestamp") → CAST(... AS TIMESTAMP); df.filter(...) → WHERE state = 'NY'.
